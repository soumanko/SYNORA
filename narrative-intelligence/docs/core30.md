# StoryScope Core30 Documentation

## 1. What Core30 Means in StoryScope
Core30 refers to the subset of 30 most highly ranked narrative features derived through a stability-validated SHAP feature importance analysis. These features serve as the primary diagnostic signals for guiding iterative revisions in the Narrative Intelligence Engine without incurring the full 304-feature computational cost at every step.

## 2. StoryScope Feature Importance Methodology
The official methodology (defined in `storyscope/6_classification/shap_analysis.py`) uses a bootstrapped `XGBClassifier` coupled with a `shap.TreeExplainer`. 
The model evaluates the feature set with `max_depth=8` and `n_estimators=420`, using sample weights to balance Human and AI classes. 

## 3. Implementation Limitation & STATE B
**Official SHAP implementation genuinely cannot be reproduced.** 

During integration testing, direct and programmatic execution of `storyscope/6_classification/shap_analysis.py` failed with the following exact technical limitation:
`ImportError: DLL load failed while importing _sparsetools: An Application Control policy has blocked this file`

This is an OS-level Application Control policy blocking the execution of `scipy.sparse` (a dependency of `shap`). Consequently, the official SHAP ranking algorithm cannot be executed on this machine.

## 4. XGBoost Split-Frequency Approximation
Because the official SHAP analysis cannot be reproduced, **no claim of official Core30 reproduction is made.** 
Instead, we use a fallback approximation generated by `approximate_core30.py` and saved as `core30_approximation.json`.

**Approximation Methodology**:
The approximation counts the raw split frequency of features inside the decision trees of the pre-trained `binary_full.json` XGBoost model. 
- Features are mapped from their 462 encoded columns back to their 304 base taxonomy IDs.
- The total split count across all trees is used as a proxy for importance.

**WARNING**: Core30 approximation based on XGBoost split-frequency importance. This is not equivalent to the StoryScope SHAP analysis.

## 5. Model and Dataset
- **Model Target**: Binary classification (Human vs. AI)
- **Source Model**: `binary_full.json`
- **Source Commit**: `main`

## 6. Integration
The `Core30Selector` class consumes the `core30_approximation.json` artifact generated by this pipeline. Narrative Forge relies exclusively on this stable ranking to formulate its `DiagnosticRecommendation` during the `RevisionPlanner` phase.
